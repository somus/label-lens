# labellens-keymap(1)

Default keybindings for the review screen. Press `?` in-app for the live,
scope-aware list.

## Review actions

- `a` — accept prediction
- `r` — open relabel picker
- `1`–`9` — relabel by index
- `x` — reject
- `s` — skip
- `m` — toggle mark
- `n` — open note
- `u` — undo

## Navigation

- `j` — next record
- `k` — previous record
- `[` — previous queue
- `]` — next queue
- `g d` — open document for this record (boundary task)
- `shift+q` — open queue screen

## Palette / help / guidelines

- `:` — command palette
- `?` — contextual help
- `g g` — guidelines viewer

## Document viewer

- `g g` — top of document
- `shift+g` — bottom of document
- `shift+j` / `shift+k` — page down / up
- `n` / `p` — next / previous matching record
- `esc` — back to review screen
